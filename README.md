# Hand-Mouse: MediaPipe 기반 실시간 핸드 트래킹 가상 마우스

**Hand-Mouse**는 Google의 최신 **MediaPipe Hand Landmarker (Tasks Vision API)**를 활용하여 웹캠이나 스마트폰 카메라 영상 속 21개 3D 손 랜드마크를 실시간 추적하고, 자연스러운 손가락 제스처로 PC 마우스(커서 이동, 클릭, 드래그)를 제어하는 오픈소스 가상 마우스 프로젝트입니다.

---

## 📌 주요 특징

- **커서 안정화 (펜 모드)**
  - **손 관절 흔들림 거르기**: MediaPipe가 준 21개 손 관절 좌표 자체를 먼저 걸러서(1-Euro 필터), 커서 떨림과 손가락 거리 판정 오류를 함께 줄입니다.
  - **멈추면 붙잡기**: 엄지+검지를 붙인 채 손이 0.2초쯤 거의 멈추면 커서를 그 자리에 붙잡고, 손바닥 폭의 5% 이상 분명히 움직이면 풀립니다.
  - **느릴 때 더 정밀하게**: 아주 천천히 움직이면 커서는 0.25배로 움직입니다.
  - **흔들림 측정**: 카메라 창 위쪽 줄에 카메라 해상도와 `Shake raw/out`(거르기 전/후 커서 흔들림 픽셀), 붙잡힌 동안 `LOCK`이 보입니다.
- **위아래 = 손을 앞뒤로**: 펜 모드에서 위아래는 손을 앞(위)·뒤(아래)로 옮겨서 합니다. 비스듬한 카메라를 위해 앞뒤 움직임을 `I`/`K`(도화지 기울기)로 키우거나 줄일 수 있습니다. 예전처럼 세 손가락 말기로 하려면 설정에서 `"vertical_source": "fingers"`.
- **엄지 끝 커서 (선택, 엄지 모드 — `M`으로 전환)**: 손은 편하게 둔 채 **엄지 끝만 움직여** 커서를 조종합니다.
  - 엄지 끝 위치는 손 안에서 잽니다(손목 기준, 손의 방향과 크기 기준). 그래서 손 전체를 옮기거나 돌리거나 카메라에서 멀어져도 커서는 그대로이고, 엄지가 움직인 만큼만 움직입니다.
  - **영점**: 처음 실행할 때, 그리고 카메라 창 오른쪽 위 **[영점 재설정]** 버튼(또는 `Z`)을 누를 때마다 진행됩니다. 커서가 모니터 모서리(왼쪽 위 → 오른쪽 위 → 오른쪽 아래 → 왼쪽 아래)로 가면, 엄지 끝을 그 모서리로 쓸 자리에 두고 잠깐(0.7초) 멈추세요. 다음 모서리는 엄지를 옮긴 뒤 잡힙니다. 네 자리가 모니터 전체가 되고, 카메라 창의 손 위에 초록 사각형(엄지 트랙패드)으로 보입니다.
  - **클릭 (손가락 펴기)**: 손을 가볍게 쥔 상태에서 **검지를 펴면 좌클릭**, **검지+중지를 펴면 우클릭**입니다. 0.15초 그 모양을 유지하면 한 번 클릭되고, 다음 클릭은 손가락을 다시 말았다 펴야 합니다(빠르게 두 번 = 더블클릭). 우클릭할 때 검지가 조금 먼저 펴져도 좌클릭이 먼저 나가지 않습니다. 처음에 손이 펴진 채로 보이면 한 번 쥘 때까지는 클릭하지 않습니다.
  - 클릭하는 동안 엄지가 조금 밀려도 커서는 직전(0.25초 전) 위치로 되돌려 그 자리에서 클릭하고, 클릭 뒤 잠깐 그대로 둡니다. 엄지가 다른 손가락에 닿는 것은 클릭이 아닙니다.
  - 카메라 창에는 검지·중지 끝 옆에 펴진 정도가 표시되고, 펴졌다고 판단되면 초록색이 됩니다.
  - `M`으로 예전 방식(범위 모드, 펜 모드, 절대 모드)으로 바꿀 수 있습니다.
- **정밀한 21개 손 랜드마크 실시간 추적**: MediaPipe Tasks Vision 모델을 통한 안정적인 손 인식.
- **책상 위 가상 도화지(펜 모드, 기본)**: 카메라가 책상을 위에서(또는 비스듬히) 내려다보고, 책상 위에 모니터 역할을 하는 수평 도화지가 깔려 있다고 생각합니다.
  - 엄지+검지를 붙이면 펜을 내린 것입니다. 펜을 내린 동안:
    - **좌우**: 손을 옆으로 옮깁니다(손목을 돌리듯). 팔꿈치를 축으로 곡선을 그려도 커서는 직선으로 움직입니다.
    - **상하**: 중지·약지·새끼손가락 세 개를 손바닥 쪽으로 말면 아래로, 바깥으로 펴면 위로 움직입니다. 세 손가락을 함께 보기 때문에 엄지+중지, 엄지+약지 클릭과 섞이지 않고, 펜을 내린 동안에는 클릭이 되지 않습니다.
  - **영점 맞추기 (2단계)**: 실행할 때마다 먼저 진행되고(카메라 위치가 바뀌어도 맞게), 쓰는 도중에는 카메라 창 오른쪽 위 **[영점 재설정]** 버튼(또는 `Z`, 휴대폰 화면의 버튼)으로 언제든 다시 할 수 있습니다. `H`는 1단계만, `V`는 2단계만. `Esc`로 건너뛰면 저장된 값을 씁니다.
    1. **좌우**: 엄지+검지를 붙이고 **오른쪽으로 먼저** 움직인 뒤 좌우로 여러 번 왔다 갔다 하세요. 겹친 선이 진해지고, 그 선 뭉치의 평균 방향이 화면 가로가 됩니다. 이때 손이 오간 범위도 기억해 둡니다.
    2. **모서리 4곳**: 왼쪽 위 → 오른쪽 위 → 오른쪽 아래 → 왼쪽 아래 순서로, 커서가 그 모서리로 가 있는 동안 그 모서리로 보낼 손모양을 하고 엄지+검지를 붙여 잠깐(0.6초) 멈췄다 떼세요.
       - 왼쪽/오른쪽 = 1단계처럼 편하게 왼쪽/오른쪽 끝으로 (손을 옮기든 손목을 돌리든, 실제로 한 쪽을 자동으로 씀), 위 = 중지·약지·새끼 활짝 펴기, 아래 = 손바닥 쪽으로 끝까지 말기
       - 모서리의 왼쪽·오른쪽 차이가 작으면 1단계에서 손이 오간 범위를 대신 써서, 같은 단계를 무한히 반복하지 않습니다.
  - **범위 모드(선택)**: 영점에서 잡은 손 범위가 모니터 전체입니다. 상하는 **세 손가락을 만 정도**(손 크기 대비 비율), 좌우는 영점에서 실제로 한 동작(**손목 회전 각도** 또는 **손바닥 폭 단위의 손 위치**)으로 정해집니다. 엄지+검지를 붙인 동안 커서가 그곳으로 움직이고, 떼면 커서는 멈춥니다. 카메라 창에는 손목에서 뻗은 왼쪽 끝/오른쪽 끝 선과 지금 손 방향(초록), 오른쪽 위 작은 모니터 그림에 손이 가리키는 곳이 보입니다. `M`으로 펜 모드(들었다 놓기)·절대 모드로 바꿀 수 있고, 펜 모드의 가로 방향은 `H`(좌우로 여러 번 왔다 갔다)로 맞춥니다.
  - 천천히 움직이면 커서도 천천히(최대 1/5) 움직여 미세 조작이 쉽고, 빠르게 휘두르면 멀리 갑니다.
  - 손가락을 떼면 펜을 든 것이라 커서는 그 자리에 남습니다. 떼는 순간 손가락이 벌어지며 밀린 작은 움직임은 되돌립니다. 다른 곳에서 다시 붙이면 거기서 이어서 움직입니다(마우스를 들었다 놓는 느낌).
  - 카메라 창에는 펜 위치를 지나는 가로 기준선과 오른쪽 방향 화살표가 그려집니다.
- **손가락 구분 판정**: 엄지와 각 손가락 끝의 거리를 손 크기로 나눠 비교하고, 가장 가까운 손가락이 다른 손가락보다 확실히 가까울 때만 인정합니다. 거리는 화면의 x, y 좌표만으로 잽니다. 클릭은 3프레임 유지되면 한 번만 실행되고(누르고 있어도 반복 클릭 없음), 누르고 있는 동안 옆 손가락으로 넘어가지 않습니다.
  - 카메라 창에는 각 손가락 끝 옆에 엄지까지의 거리가 표시되고, 붙었다고 판단되면 초록색이 됩니다. 연결선은 실제로 붙은 손가락에만 그려집니다.
- **유연한 카메라 입력 지원**: 일반 PC 웹캠 및 스마트폰 카메라(IP Webcam Wi-Fi 스트리밍, DroidCam/Iriun 가상 웹캠) 완벽 지원.
- **다양한 제스처 동작**: 좌클릭, 우클릭, 드래그 홀드, 드래그 토글 지원.
- **런타임 핫 리로드 (Hot-reload)**: `config/gestures.json` 수정 후 앱을 재시작하지 않고 `R` 키로 즉시 반영.

## 🚀 시작하기

### 1. 환경 설정 및 실행

본 프로젝트는 `uv` 패키지 관리자를 사용합니다.

**다른 PC에서 처음 실행할 때는 `run.bat`을 더블클릭하세요.** uv가 없으면 공식 스크립트로 설치하고(관리자 권한 불필요, 인터넷 필요),
Python 3.12와 패키지를 이 폴더의 `.venv`에 받은 뒤 앱을 실행합니다. 첫 실행은 몇 분 걸리고, 다음부터는 바로 켜집니다.
옵션도 그대로 넘길 수 있습니다: `run.bat --phone-web`, `run.bat --source 1`

uv가 이미 있으면 아래처럼 직접 실행해도 같습니다(가상환경과 패키지는 처음 한 번 자동으로 준비됩니다).

```bash
# 1. USB 웹캠으로 실행 (SNAP U2 등 기본 0번 카메라)
uv run python main.py --source 0

# 2. 무설치 스마트폰 웹브라우저 카메라로 실행 (별도 앱 설치 불필요! 적극 추천)
uv run python main.py --phone-web

# 3. 스마트폰 IP 카메라(IP Webcam 앱 등)로 실행
uv run python main.py --source 192.168.0.15:8080

# 4. 카메라 영역 = 화면 전체(절대 좌표) 모드로 실행
uv run python main.py --mode absolute

# 5. 모의 실행(dry-run: 실제 마우스 클릭/이동 없이 화면에만 표시)
uv run python main.py --dry-run
```

### 2. 주요 실행 옵션

| 옵션 | 설명 | 기본값 |
| :--- | :--- | :--- |
| `--source` | 카메라 인덱스 (`0`, `1`) 또는 `phone`(웹브라우저 모드), 스마트폰 IP/URL (`192.168.x.x:8080`, `rtsp://...`) | `0` |
| `--phone-web` | **무설치 스마트폰 웹브라우저 카메라 모드** 즉시 실행 (`--source phone`과 동일) | `False` |
| `--phone-port` | 스마트폰 웹브라우저 연결용 로컬 HTTPS/WSS 서버 포트 | `8443` |
| `--mode` | 커서 이동 방식 (`range`: 손 범위 = 모니터, `relative`: 펜 들었다 놓기, `absolute`: 카메라 영역 = 화면) | `config` 파일 기준 (`range`) |
| `--dpi` | 커서 속도 배율 (클수록 손을 조금만 움직여도 멀리 감 = 도화지가 작아짐) | `config` 파일 기준 (`1.0`) |
| `--config` | 커스텀 제스처 설정 파일 경로 | `config/gestures.json` |
| `--dry-run` | 실제 OS 마우스 이벤트를 발생시키지 않고 시각화만 수행 | `False` |
| `--no-mirror`| 카메라 화면 좌우 반전(거울 모드) 비활성화 | `False` (기본 거울 모드) |

## 📱 스마트폰 카메라 연동 방법

별도의 고가 웹캠 없이도 스마트폰 카메라를 고화질 마우스 입력 장치로 손쉽게 활용할 수 있습니다.

### 방법 1: 무설치 스마트폰 웹브라우저 카메라 모드 (`--phone-web` / 실행 중 `P` 키, 적극 추천!)

**스마트폰에 어떠한 앱도 설치할 필요가 없습니다.** iOS Safari 또는 Android Chrome만 있으면 즉시 작동합니다.

1. **PC에서 실행**:
   ```bash
   uv run python main.py --phone-web
   ```
   *(이미 USB 웹캠 모드로 실행 중인 경우에도 카메라 창에서 **`P` 키**를 누르면 즉시 웹브라우저 카메라 대기 모드로 전환됩니다.)*
2. **QR 코드 스캔 또는 HTTPS 주소 접속**:
   - PC 화면에 scannable QR 코드와 주소(예: `https://10.10.21.17:8443`)가 표시됩니다.
   - 스마트폰 기본 카메라 앱으로 QR 코드를 비추거나 모바일 브라우저 주소창에 직접 입력합니다.
3. **자체 서명 인증서 경고 허용**:
   - PC 로컬 자체 서명 인증서이므로 브라우저에 "안전하지 않음 / 연결이 비공개로 설정되어 있지 않습니다" 경고가 나타납니다.
   - **[고급] → [안전하지 않음으로 이동] / [계속 방문]**을 터치합니다.
4. **카메라 권한 허용 및 실시간 스트리밍**:
   - 브라우저의 카메라 권한 요청을 [허용]하면 스마트폰 화면에 카메라 프리뷰가 표시되고, 즉시 PC로 실시간 영상이 전송되어 핸드 트래킹이 시작됩니다.
   - 모바일 웹 화면에서 전면/후면 카메라 전환, 해상도 및 FPS 조절도 가능합니다.

> 💡 **네트워크 연결 팁 (네트워크 대역이 다를 때)**:
> - PC가 유선랜(`10.10.21.x`)에 물려있고 스마트폰이 별도 공유기 Wi-Fi(`192.168.0.x`)에 연결되어 있으면 서로 직접 접속이 안 될 수 있습니다.
> - **해결책 1 (가장 간편)**: 스마트폰을 USB 케이블로 PC에 연결한 뒤, 스마트폰 **[설정] → [개인용 핫스팟 / 테더링] → [USB 테더링]**을 켜면 PC와 스마트폰이 직접 같은 로컬 네트워크로 연결되어 즉시 접속됩니다!
> - **해결책 2**: PC와 스마트폰을 동일한 Wi-Fi 공유기 네트워크에 연결합니다.

### 방법 2: IP Webcam 앱 (Wi-Fi 무선 스트리밍)
1. 스마트폰(Android)에 **IP Webcam** 앱을 설치합니다.
2. 앱 하단의 **[Start server]**를 터치합니다.
3. 화면 하단에 표시되는 IP 주소와 포트(예: `192.168.0.15:8080`)를 확인합니다.
4. PC에서 아래와 같이 실행합니다 (자동으로 `http://.../video` 스트림으로 변환됩니다):
   ```bash
   uv run python main.py --source 192.168.0.15:8080
   ```

### 방법 3: DroidCam / Iriun Webcam (가상 웹캠)
1. 스마트폰과 PC에 각각 **DroidCam** 또는 **Iriun 4K Webcam**을 설치하고 연동합니다.
2. PC에 가상 웹캠 장치(보통 장치 번호 `1` 또는 `2`)로 인식됩니다.
3. 가상 웹캠 인덱스를 지정하여 실행합니다:
   ```bash
   uv run python main.py --source 1
   ```
   *(실행 중에도 카메라 창에서 `C` 키를 누르면 로컬 웹캠 인덱스를 순환 전환할 수 있습니다.)*

## ✋ 기본 손동작 (Default Gestures)

| 손가락 제스처 | 동작 (Action) | 설명 |
| :--- | :--- | :--- |
| **엄지 + 검지 핀치 (맞닿음)** | **펜 내림 = 커서 이동** (`move_cursor`) | 붙인 채로 손을 옆으로 옮기면 좌우, 중지·약지·새끼를 말면 아래·펴면 위로 움직입니다. 떼면 펜을 든 것이라 커서가 그 자리에 남습니다. |
| **엄지 + 중지 핀치** | **좌클릭** (`left_click`) | 붙일 때마다 한 번 클릭합니다. 빠르게 두 번 붙이면 더블클릭. |

> 엄지가 검지에 붙어 커서를 움직이던 중이라도, 엄지를 중지(또는 약지) 끝으로 옮겨 그쪽이 확실히 더 가까워지면 바로 클릭됩니다(상하가 손 앞뒤 이동일 때).
| **엄지 + 약지 핀치** | **우클릭** (`right_click`) | 붙일 때마다 한 번 우클릭합니다. |
| **엄지 + 검지 + 중지 동시 핀치** | **누른 채 끌기** (`drag_hold`) | 기본 꺼짐. 켜면 세 손가락을 모은 동안 왼쪽 버튼을 누른 채 움직입니다. |
| **엄지 + 소지(새끼) 핀치** | **끌기 켜기/끄기** (`drag_toggle`) | 기본 꺼짐. 켜면 붙일 때마다 왼쪽 버튼 누름/뗌이 바뀝니다. |

> **가로 방향**: 영점 맞추기에서 그린 가로선이 기준입니다. 조금 비스듬하면 **`J` / `L`** 로 2°씩 다듬고 **`S`** 로 저장하세요. 좌우가 반대로 움직이면 **`F`**. 영점 맞추기는 처음 실행할 때 `Esc`로 건너뛸 수 있고, 그 경우 손이 가리키는 방향을 기준으로 씁니다.

## ⌨️ 카메라 창 단축키 안내

카메라 화면 창이 활성화된 상태에서 아래 키를 입력하여 실시간으로 기능을 제어할 수 있습니다.

- **`Space`** : 마우스 제어 일시정지(Pause) / 재개(Resume) 토글 (화면 조작 중 잠시 멈출 때 유용)
- **`M`** : 이동 모드 전환 (펜 모드 `relative` ↔ 절대 좌표 `absolute`)
- **`[` / `]`** 또는 카메라 창 위쪽 **[-] / [+] 버튼** : 커서 속도 낮춤 / 높임 (바로 저장됨)
- 단축키는 **카메라 창이 앞에 있을 때** 동작합니다. 한글 입력 상태여도 됩니다. 손으로 다른 창을 클릭해 키가 안 먹으면 카메라 창을 한 번 클릭하세요.
- **`+` / `-`** : 핀치 인식 감도 미세 조정 (`+`: 더 민감하게, `-`: 더 엄격하게)
- **`Z`** 또는 **[영점 재설정] 버튼** : 영점 맞추기 (1단계 좌우 왕복 → 2단계 모서리 4곳)
- **`H`** : 1단계(좌우 왕복)만 다시 맞추기
- **`V`** : 2단계(모서리 4곳)만 다시 맞추기
- **`M`** : 이동 방식 전환 (범위 → 펜 → 절대)
- **`D`** : 핀치 기록 저장 — 클릭이 안 잡혔을 때 바로 누르면 직전 약 6초의 손가락 거리 기록이 `logs/`에 CSV로 저장됩니다. 이 파일을 보내 주시면 원인을 정확히 볼 수 있습니다.
- **`X`** : 영점 지우기 (손이 가리키는 방향을 기준으로 씀)
- **`J` / `L`** : 가로 기준선을 2°씩 돌려 미세 조정 (커서가 위나 아래로 비스듬히 샐 때)
- **`I` / `K`** : 상하(손가락 말기) 속도 올림 / 내림
- **`F`** : 도화지 좌우 방향 뒤집기 (커서 좌우가 손과 반대로 갈 때)
- **`C`** : 로컬 웹캠 장치 인덱스 순환 전환 (`0` → `1` → `2` → `0`)
- **`P`** : 무설치 스마트폰 웹브라우저 카메라 모드 (`phone-web`)로 전환 (QR 코드 안내 화면)
- **`R`** : `config/gestures.json` 설정 파일 실시간 재로드 (**핫 리로드**)
- **`S`** : 현재 런타임에서 변경된 감도 및 설정을 `config/gestures.json`에 영구 저장
- **`Q` / `ESC`** : 프로그램 안전 종료 및 리소스 해제

## ⚙️ 설정 커스터마이징 (`config/gestures.json`)

`config/gestures.json` 파일에서 각 제스처의 동작 매핑 및 인식 파라미터를 원하는 대로 수정할 수 있습니다.

```jsonc
{
  "pinch_threshold": 0.055,     // 엄지+검지 펜 내림 거리 (작을수록 더 꼭 붙여야 함)
  "release_threshold": 0.08,    // 이 거리보다 벌어지면 뗀 것으로 봄
  "click_threshold": 0.075,     // 엄지+중지/약지/소지 클릭 거리
  "finger_separation": 0.75,    // 가장 가까운 손가락이 두 번째보다 이 비율 이하로 가까워야 인정
  "click_confirm_frames": 2,    // 클릭이 실행되기 전 유지해야 하는 프레임 수
  "click_separation": 0.8,      // 클릭 손가락은 다음으로 가까운 (동작이 있는) 손가락보다 이 비율 이하로 가까워야 함
  "movement_mode": "relative",  // "relative"(도화지 펜) 또는 "absolute"
  "pen_speed": 2.0,             // 손바닥 한 폭 움직일 때 커서가 가는 거리(화면 폭 비율)
  "paper_x_angle_deg": null,    // 영점 맞추기로 잰 가로 방향 (null이면 실행할 때 영점 맞추기부터 시작)
  "calib_target_length": 6.0,   // 영점 맞추기 완료에 필요한 좌우 이동 총량 (손바닥 폭 단위)
  "calib_bundle_deg": 20.0,     // 가장 진한 방향에서 이 각도 안의 선만 평균에 넣음
  "paper_rotation_deg": 0,      // 가로 방향 미세 조정 (J/L 키, 2도씩)
  "vertical_source": "fingers", // 상하 이동: "fingers"(세 손가락 말기) 또는 "hand"(손을 앞뒤로 이동)
  "curl_gain": 0.45,            // 한 번 끝까지 말 때 커서가 내려가는 양 (I/K 키)
  "curl_open": null,            // 상하 영점에서 잰 '끝까지 폈을 때' 값
  "curl_closed": null,          // 상하 영점에서 잰 '끝까지 말았을 때' 값
  "calibrate_on_start": true,   // true면 실행할 때마다 영점 맞추기 (false: 처음 한 번만, Esc로 건너뛰기)
  "range_left_deg": null,       // 모서리 맞추기로 잰 손목 회전 각도 (왼쪽 끝/오른쪽 끝)
  "range_right_deg": null,
  "range_top": null,             // 위/아래 끝의 세 손가락 상태 (펴기/말기)
  "range_bottom": null,
  "corner_hold_s": 0.6,         // 모서리마다 엄지+검지를 붙이고 멈춰야 하는 시간
  "pen_takeover_window_s": 0.25,// 펜을 내린 뒤 이 시간이 지나면 클릭으로 넘어가지 않음 (말기와 클릭 구분)
  "paper_tilt_deg": 45,         // "hand" 모드일 때만: 도화지 기울기, 앞뒤 움직임을 1/cos(각도)배로 늘림
  "dpi_scale": 1.0,             // 속도 배율 ([ / ] 키나 창의 - / + 버튼으로 조절)
  "paper_depth_gain": 1.0,      // 앞뒤(화면 위아래) 움직임 배율 (1.0 = 손의 x, y 그대로)
  "straighten_arcs": true,      // 팔꿈치를 축으로 손이 곡선을 그려도 커서는 직선으로
  "paper_invert_x": true,       // 도화지 좌우 뒤집기 (F 키)
  "pen_finger_weight": 0.3,     // 펜 위치에서 손가락 끝 비중 (나머지는 손등 관절, 펜을 들고 놓을 때 튐 방지)
  "pointer_acceleration": true, // 속도별 배율: 천천히 움직이면 커서도 덜 움직여 미세 조작이 쉬움
  "accel_min_gain": 0.25,        // 아주 천천히 움직일 때 배율
  "accel_max_gain": 1.8,        // 빠르게 휘두를 때 배율
  "accel_low_speed": 0.15,      // 이 속도(초당 손바닥 폭) 이하면 최소 배율
  "accel_high_speed": 1.5,      // 이 속도 이상이면 최대 배율
  "lift_rollback_s": 0.12,      // 펜을 들 때 손가락이 벌어지며 밀린 직전 0.12초 움직임을 되돌림
  "lift_rollback_max_px": 60,   // 그보다 크게 움직였으면(빠른 휘두름) 되돌리지 않음
  "one_euro_min_cutoff": 0.8,   // 멈춰 있을 때 떨림 보정 세기 (작을수록 강함)
  "one_euro_beta": 1.5,         // 빠르게 움직일 때 보정을 푸는 정도 (클수록 덜 굼뜸)
  "deadzone_px": 2.5,           // 이보다 작은 흔들림은 무시
  "smoothing": 0.35,            // 커서 떨림 보정 (0에 가까울수록 부드러움)
  "gestures": { ... }           // 손동작별 동작 매핑 (move_cursor, left_click, right_click, drag_hold, drag_toggle, none)
}
```

> **Tip**: 파일을 편집한 후 애플리케이션을 종료할 필요 없이 카메라 창에서 **`R` 키**를 누르면 즉시 새로운 설정이 반영됩니다.
